**ดอกเตอร์ลอว์เยอร์ (Doctor Lawyer)** คือแพลตฟอร์มคัดกรองข้อพิพาททางกฎหมาย ปรึกษาข้อกฎหมายไทยเบื้องต้น และเชื่อมต่อส่งต่อลูกความให้แก่เครือข่ายทนายความพาร์ตเนอร์ผ่าน **LINE Official Account (LINE OA)**

ออกแบบด้วยสถาปัตยกรรม **Two-Tier Engine** ที่มุ่งเน้นความแม่นยำสูง (Zero Hallucination), ประหยัดต้นทุนขั้นสุด (Tier 1 ทำงานได้โดยไม่เสียค่า Token แม้แต่บาทเดียว), ปลอดภัยตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA), และมีระบบจำกัดสิทธิ์โควตาผู้ใช้งานอย่างเป็นธรรม

---

## 🌟 จุดเด่นของระบบ (Key Features)

- ⚡ **สถาปัตยกรรม 2 ระดับ (Two-Tier Consultation Engine):**
  - **Tier 1 (Built-in Rule Engine):** ประมวลผลข้อกฎหมายตรงตัวจากฐานข้อมูล 11 หมวดหมู่และแนวคำพิพากษาศาลฎีกา 33 เรื่อง ตอบกลับในเวลา `< 1 มิลลิวินาที` **กิน 0 Tokens (ต้นทุน 0 บาท)**
  - **Tier 2 (AI Router & Fallback):** สลับไปใช้ AI เมื่อพบคำถามกำกวม ซับซ้อน หรือเป็นคดีเฉพาะทาง รองรับ API Key ราคาประหยัด (Gemini Flash, GPT-4o-mini, DeepSeek) พร้อมระบบ Smart Heuristic ในตัว
- 🛡️ **คุ้มครองข้อมูลส่วนบุคคล (PDPA Automatic Masking):**
  - เซ็นเซอร์เลขประจำตัวประชาชน 13 หลัก, เลขที่บัญชีธนาคาร, และเบอร์โทรศัพท์ออกโดยอัตโนมัติก่อนนำไปวิเคราะห์
- 🔒 **ระบบควบคุมสิทธิ์และยืนยันตัวตน (User Authentication & Quotas):**
  - **ผู้ใช้งานทั่วไป (Guest):** ทดลองใช้งานฟรีได้ **1 ครั้ง**
  - **สมาชิก Google Account:** ล็อกอิน 1 คลิก ยืนยันตัวตนอัตโนมัติ ได้รับฟรี **3 ครั้ง**
  - **สมาชิก Email:** กรอกอีเมลและยืนยันรหัส **OTP 6 หลัก (อายุ 15 นาที)** เพื่อป้องกันการกรอกอีเมลปลอม เมื่อยืนยันสำเร็จได้รับฟรี **3 ครั้ง**
- 💬 **ส่งต่องานทนายความพาร์ตเนอร์ผ่าน LINE OA (Partner Lawyer Handoff):**
  - สังเคราะห์ **"ใบสรุปข้อมูลคดี (Case Intake Brief)"** ประกอบด้วยข้อเท็จจริง (เซ็นเซอร์ PDPA), มาตรากฎหมาย, ฎีกาที่เกี่ยวข้อง และรายการเอกสารที่ต้องใช้
  - กดปุ่มเดียว คัดลอกสรุปคดีลงคลิปบอร์ดทันที พร้อมเด้งเปิดหน้าแชท LINE OA เพื่อให้ลูกความวางข้อความคุยกับทนายความต่อได้ทันที
- 📱 **รองรับ Web Browser และ LINE LIFF:**
  - ใช้งานได้ทั้งบน Desktop, Mobile Web, และเปิดเป็น Web App ภายในแอป LINE ผ่าน LINE LIFF

## 🏛️ ฐานข้อมูลกฎหมาย 11 หมวดหมู่และ 33 คำพิพากษาศาลฎีกา

ระบบบรรจุข้อกฎหมายไทยและคำพิพากษาศาลฎีกาครอบคลุม 11 หมวดหมู่สำคัญ:
1. `CAT-01`: อาชญากรรมทางเทคโนโลยี หลอกโอนเงิน บัญชีม้า (พ.ร.ก. ไซเบอร์ฯ 2566, อายัด AOC 1441 ทันที 72 ชม.)
2. `CAT-02`: หนี้สิน สัญญากู้ยืม และดอกเบี้ยนอกระบบ (ป.พ.พ. ม.653, ม.654 ดอกเบี้ยเกิน 15%/ปี โมฆะทั้งหมด)
3. `CAT-03`: แรงงาน การเลิกจ้าง และเงินชดเชย (พ.ร.บ.คุ้มครองแรงงาน ม.118 ค่าชดเชย, ม.17 ค่าตกใจ)
4. `CAT-04`: ละเมิด อุบัติเหตุจราจร และการเรียกค่าเสียหาย (ป.พ.พ. ม.420, ค่าขาดประโยชน์ระหว่างซ่อม 500 บ./วัน)
5. `CAT-05`: ครอบครัว มรดก พินัยกรรม และสมรสเท่าเทียม (ป.พ.พ. ม.1448, ม.1599, ม.1629)
6. `CAT-06`: เช่าทรัพย์ เช่าซื้อ และการขับไล่ (ป.พ.พ. ม.537, คืนรถเช่าซื้อขณะไม่ผิดนัดไม่ต้องจ่ายส่วนต่าง ฎีกา 143/2565)
7. `CAT-07`: คุ้มครองผู้บริโภคและสินค้าชำรุดบกพร่อง (พ.ร.บ.คุ้มครองผู้บริโภค, สคบ. สายด่วน 1166)
8. `CAT-08`: หมิ่นประมาทและการโพสต์ประจานออนไลน์ (ป.อ. ม.326, ม.328, พ.ร.บ.คอมพิวเตอร์ฯ, พ.ร.บ.ทวงหนี้ฯ)
9. `CAT-09`: คดีอาญาทั่วไปและความผิดต่อชีวิต/ร่างกาย/ทรัพย์ (ป.อ. ม.295 ทำร้ายร่างกาย, ม.334 ลักทรัพย์, ม.352 ยักยอก)
10. `CAT-10`: การไกล่เกลี่ยข้อพิพาทก่อนฟ้อง (ป.วิ.พ. ม.20 ตรี ไกล่เกลี่ยก่อนฟ้อง ฟรีไม่มีค่าธรรมเนียมศาล)
11. `CAT-11`: ภาษีอากรสำหรับพ่อค้า/แม่ค้าออนไลน์ (ป.รัษฎากร e-Payment 400 ครั้ง+2 ล้าน หรือ 3,000 ครั้ง, ยอดเกิน 1.8 ล้านจด VAT)

## 🚀 การเริ่มต้นใช้งานด่วน (Quick Start)

### 1. เรียกใช้งานบนเครื่อง Local
```powershell
# รันเซิร์ฟเวอร์บนพอร์ต 3000
python -X utf8 backend\main.py

# หรือดับเบิ้ลคลิกไฟล์:
scripts\start_server.bat
```
เปิดใช้งานผ่านเบราว์เซอร์ได้ที่: **`http://localhost:3000`**

### 2. รันชุดทดสอบระบบ (End-to-End Test Suite)
```powershell
python -X utf8 scripts\test_two_tier_pipeline.py

# หรือดับเบิ้ลคลิกไฟล์:
scripts\test_pipeline.bat
```

### 3. เปิด Live Demo ผ่าน HTTPS สาธารณะทันที (0 บาท / 0 ติดตั้ง)
```powershell
scripts\start_public_tunnel.bat
```
ระบบจะสร้าง HTTPS URL สาธารณะให้ทันที สามารถนำลิงก์ไปเปิดบนมือถือหรือส่งให้ลูกค้าทดลองใช้งานได้ทันที

## 🌐 การนำไป Deploy ขึ้น Cloud Host

### ทางเลือกที่ 1: Deploy บน Render.com (ฟรี + ได้ HTTPS ถาวร)
โปรเจกต์มีไฟล์ `render.yaml` เตรียมไว้แล้ว:
1. Push โปรเจกต์ขึ้น GitHub
2. ไปที่ [render.com](https://render.com) ➔ กด **New +** ➔ เลือก **Blueprint** ➔ เลือก Repository ของคุณ
3. Render จะอ่านการตั้งค่าจาก `render.yaml` และ Deploy ให้อัตโนมัติ

### ทางเลือกที่ 2: Deploy ด้วย Docker
```bash
docker build -t doctor-lawyer .
docker run -p 3000:3000 doctor-lawyer
```

## 📡 REST API Reference

| Endpoint | Method | คำอธิบาย |
| :--- | :---: | :--- |
| `/api/consult` | `POST` | ส่งข้อเท็จจริงเพื่อรับการวิเคราะห์กฎหมาย 6 ขั้นตอน |
| `/api/auth/email/request-otp` | `POST` | ขอรับรหัส OTP 6 หลักทางอีเมล (ป้องกันอีเมลปลอม) |
| `/api/auth/email/verify-otp` | `POST` | ยืนยันรหัส OTP เพื่อเปิดสิทธิ์ใช้งานฟรี 3 ครั้ง |
| `/api/auth/google` | `POST` | เข้าสู่ระบบด้วย Google Account (รับสิทธิ์ฟรี 3 ครั้งทันที) |
| `/api/auth/me` | `GET` | ตรวจสอบสถานะผู้ใช้และโควตาคงเหลือ |
| `/api/health` | `GET` | ตรวจสอบสถานะการทำงานของระบบและเครื่องยนต์วิเคราะห์ |
| `/api/statutes` | `GET` | ดึงรายชื่อหมวดหมู่กฎหมายและคีย์เวิร์ดทั้งหมด 11 หมวด |
| `/api/quota` | `GET` | ตรวจสอบโควตาคงเหลือของผู้ใช้ปัจจุบัน |
