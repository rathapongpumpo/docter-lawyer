# หมวดที่ CAT-09: คดีอาญาพื้นฐาน ทรัพย์สิน และร่างกาย
**English:** Basic Criminal Offenses, Property & Bodily Harm

> 📌 **คำอธิบายขอบเขต:** ครอบคลุมการทำร้ายร่างกาย ลักทรัพย์ วิ่งราวทรัพย์ ชิงทรัพย์ ยักยอกทรัพย์ และทำให้เสียทรัพย์

- **กองปราบปราม:** โทร. **1195**
- **กรมคุ้มครองสิทธิและเสรีภาพ (เงินเยียวยาผู้เสียหายในคดีอาญา):** โทร. **1111** กด 77

## ⚖️ ตัวบทกฎหมายและมาตราสำคัญ
### 📖 ประมวลกฎหมายอาญา (ความผิดต่อชีวิตและร่างกาย)
#### **มาตรา 295 — ความผิดฐานทำร้ายร่างกาย**
> ผู้ใดทำร้ายผู้อื่น จนเป็นเหตุให้เกิดอันตรายแก่กายหรือจิตใจของผู้อื่นนั้น ผู้นั้นกระทำความผิดฐานทำร้ายร่างกาย ต้องระวางโทษจำคุกไม่เกินสองปี หรือปรับไม่เกินสี่หมื่นบาท หรือทั้งจำทั้งปรับ

- **อัตราโทษ:** จำคุกไม่เกิน 2 ปี หรือปรับไม่เกิน 40,000 บาท หรือทั้งจำทั้งปรับ
- **ลักษณะความผิด:** เป็นอาญาแผ่นดิน ยอมความไม่ได้
- **ข้อสังเกตในทางปฏิบัติ:** คดีทำร้ายร่างกายตาม ม.295 เป็นอาญาแผ่นดิน ยอมความไม่ได้ เว้นแต่ทำร้ายเล็กน้อยไม่ถึงอันตรายแก่กาย (ลหุโทษ ม.391)

### 📖 ประมวลกฎหมายอาญา (ความผิดเกี่ยวกับทรัพย์)
#### **มาตรา 334 — ความผิดฐานลักทรัพย์**
> ผู้ใดเอาทรัพย์ของผู้อื่น หรือที่ผู้อื่นเป็นเจ้าของรวมอยู่ด้วยไปโดยทุจริต ผู้นั้นกระทำความผิดฐานลักทรัพย์ ต้องระวางโทษจำคุกไม่เกินสามปี และปรับไม่เกินหกหมื่นบาท

- **อัตราโทษ:** จำคุกไม่เกิน 3 ปี และปรับไม่เกิน 60,000 บาท

#### **มาตรา 352 — ความผิดฐานยักยอกทรัพย์**
> ผู้ใดครอบครองทรัพย์ซึ่งเป็นของผู้อื่น หรือซึ่งผู้อื่นเป็นเจ้าของรวมอยู่ด้วย เบียดบังเอาทรัพย์นั้นเป็นของตนหรือบุคคลที่สามโดยทุจริต ผู้นั้นกระทำความผิดฐานยักยอก ต้องระวางโทษจำคุกไม่เกินสามปี หรือปรับไม่เกินหกหมื่นบาท หรือทั้งจำทั้งปรับ

- **ลักษณะความผิด:** เป็นความผิดอันยอมความได้ (ต้องร้องทุกข์ภายใน 3 เดือน)
- **อายุความ:** เป็นความผิดอันยอมความได้ ต้องแจ้งความร้องทุกข์ภายใน 3 เดือน นับแต่วันรู้เรื่องความผิดและรู้ตัวผู้กระทำความผิด

#### **มาตรา 358 — ความผิดฐานทำให้เสียทรัพย์**
> ผู้ใดทำให้เสียหาย ทำลาย ทำให้เสื่อมค่าหรือทำให้ไร้ประโยชน์ ซึ่งทรัพย์ของผู้อื่นหรือผู้อื่นเป็นเจ้าของรวมอยู่ด้วย ผู้นั้นกระทำความผิดฐานทำให้เสียทรัพย์ ต้องระวางโทษจำคุกไม่เกินสามปี หรือปรับไม่เกินหกหมื่นบาท หรือทั้งจำทั้งปรับ

- **ลักษณะความผิด:** เป็นความผิดอันยอมความได้ (ต้องร้องทุกข์ภายใน 3 เดือน)
- **อายุความ:** เป็นความผิดอันยอมความได้ ต้องแจ้งความภายใน 3 เดือน

## 🏛️ คำพิพากษาศาลฎีกาที่สำคัญ (Supreme Court Precedents)
### 1. คำพิพากษาศาลฎีกาที่ 4120/2562
- **ประเด็นข้อพิพาท:** ยืมรถหรือฝากของไว้แล้วไม่ยอมคืน เป็นลักทรัพย์หรือยักยอกทรัพย์?
- **คำวินิจฉัยของศาลฎีกา:** ข้อแตกต่างระหว่างความผิดฐานลักทรัพย์กับยักยอกทรัพย์อยู่ที่สิทธิในการครอบครองทรัพย์ เมื่อผู้เสียหายได้ส่งมอบการครอบครองรถยนต์ให้แก่จำเลยด้วยความสมัครใจเพื่อใช้งาน การที่จำเลยไม่ยอมนำรถมาคืนและนำไปขายต่อ ย่อมเป็นความผิดฐานยักยอกทรัพย์ตาม ป.อ. มาตรา 352 หาใช่ความผิดฐานลักทรัพย์ไม่ ซึ่งความผิดฐานยักยอกทรัพย์เป็นความผิดอันยอมความได้ ผู้เสียหายต้องแจ้งความร้องทุกข์ภายใน 3 เดือน มิฉะนั้นคดีขาดอายุความ
- **💡 บรรทัดฐานทางกฎหมาย:** *"ฝากของหรือให้ยืมของแล้วเชิดหนี เป็นคดียักยอกทรัพย์ (ยอมความได้ ต้องแจ้งความใน 3 เดือน)"*

### 2. คำพิพากษาศาลฎีกาที่ 1511/2561
- **ประเด็นข้อพิพาท:** คดียักยอกทรัพย์ ผู้เสียหายไม่แจ้งความภายใน 3 เดือน ผลทางคดีเป็นอย่างไร?
- **คำวินิจฉัยของศาลฎีกา:** โจทก์ทราบเรื่องที่จำเลยยักยอกเงินของบริษัทและรู้ตัวจำเลยแล้ว แต่ไม่ได้ร้องทุกข์ต่อพนักงานสอบสวนภายใน 3 เดือน นับแต่วันที่รู้เรื่องความผิดและรู้ตัวผู้กระทำความผิดตาม ป.อ. มาตรา 96 คดีของโจทก์จึงขาดอายุความ สิทธินำคดีอาญามาฟ้องของโจทก์ย่อมระงับสิ้นไปตาม ป.วิ.อ. มาตรา 39(6)
- **💡 บรรทัดฐานทางกฎหมาย:** *"คดียักยอกทรัพย์ต้องแจ้งความภายใน 3 เดือน หากเกินกำหนดคดีขาดอายุความทันที"*

### 3. คำพิพากษาศาลฎีกาที่ 2294/2563
- **ประเด็นข้อพิพาท:** กระชากกระเป๋าสะพายที่ผู้เสียหายกำลังสะพายอยู่ เป็นความผิดฐานใด?
- **คำวินิจฉัยของศาลฎีกา:** จำเลยใช้มือกระชากกระเป๋าสะพายจากไหล่ของผู้เสียหายขณะกำลังเดินอยู่ริมถนนแล้ววิ่งหนีไป การกระทำของจำเลยเป็นการฉกฉวยเอาทรัพย์ซึ่งหน้า ย่อมเป็นความผิดฐานวิ่งราวทรัพย์ตาม ป.อ. มาตรา 336 มิใช่เพียงการลักทรัพย์ธรรมดา และเป็นความผิดอาญาแผ่นดินยอมความไม่ได้
- **💡 บรรทัดฐานทางกฎหมาย:** *"กระชากกระเป๋าถือเป็นการฉกฉวยซึ่งหน้า เป็นคดีวิ่งราวทรัพย์ ยอมความไม่ได้"*
