# บอกกล่าวให้แก้ไขการผิดสัญญา แล้วเลิกสัญญา

## ภาพรวม
สัญญาไม่มีข้อให้เลิกสัญญา ไม่ได้แปลว่าเลิกไม่ได้ สิทธิเลิกสัญญาเกิดจากบทบัญญัติของกฎหมายได้ด้วย [[law:ccc:386]]
ถ้าคู่สัญญาไม่ชำระหนี้ คุณกำหนดระยะเวลาพอสมควร แล้วบอกกล่าวให้ชำระภายในเวลานั้น ถ้าไม่ชำระ คุณเลิกสัญญาได้ [[law:ccc:387]]

## ใครใช้คู่มือนี้ได้
คู่สัญญาฝ่ายที่อีกฝ่ายไม่ชำระหนี้ตามสัญญา เช่น ผู้ซื้อที่ผู้ขายไม่ส่งของ หรือผู้ว่าจ้างที่ผู้รับจ้างไม่ทำงาน
ถ้าคู่สัญญาฝ่ายหนึ่งมีหลายคน ต้องใช้สิทธิเลิกสัญญาร่วมกันทั้งหมด และใช้ต่อทุกคนในฝ่ายตรงข้าม [[law:ccc:390]]

## เอกสารที่ควรเตรียม
- [ ] สัญญา และเอกสารแนบท้าย (`contract`)
- [ ] หลักฐานการไม่ชำระหนี้ เช่น ใบส่งของ รูปถ่าย ผลตรวจ (`breach_evidence`)
- [ ] สำเนาหนังสือบอกกล่าว (`notice_copy`)
- [ ] หลักฐานการส่งและการรับหนังสือ (`delivery_proof`)
- [ ] สำเนาหนังสือบอกเลิกสัญญา (`termination_copy`)

## ขั้นตอน
1. **ตรวจว่าเข้ากรณีใด**
   - ไม่ชำระหนี้ทั่วไป ต้องบอกกล่าวก่อน [[law:ccc:387]]
   - ถ้าเวลาชำระหนี้เป็นสาระสำคัญของสัญญา และพ้นกำหนดแล้ว เลิกได้โดยไม่ต้องบอกกล่าวก่อน [[law:ccc:388]]
   - ถ้าการชำระหนี้กลายเป็นพ้นวิสัยเพราะเหตุที่โทษลูกหนี้ได้ เลิกสัญญาได้ [[law:ccc:389]]
   - สัญญาจ้างทำของที่คาดได้แน่นอนว่างานจะบกพร่องเพราะความผิดของผู้รับจ้าง มีขั้นตอนบอกกล่าวให้แก้ไขเฉพาะใน ม.594 [[law:ccc:594]]
2. **ทำหนังสือบอกกล่าว** ระบุสิ่งที่ต้องแก้ไข และกำหนดเวลาที่พอสมควร ใช้แบบ [[template:notice-to-cure]]
3. **ส่งหนังสือและเก็บหลักฐานการรับ** (คำแนะนำ: ส่งทางช่องทางที่พิสูจน์การรับได้ เช่น ไปรษณีย์ลงทะเบียนตอบรับ)
4. **รอให้ครบกำหนด** ถ้าอีกฝ่ายชำระหนี้ถูกต้องภายในเวลา ก็ไม่ต้องเลิกสัญญา
5. **ถ้าครบกำหนดแล้วยังไม่ชำระ** ส่งหนังสือแสดงเจตนาเลิกสัญญา ใช้แบบ [[template:termination-notice]] การแสดงเจตนาเลิกสัญญาถอนไม่ได้ [[law:ccc:386#p2]]
6. **จัดการผลของการเลิกสัญญา** แต่ละฝ่ายต้องให้อีกฝ่ายกลับคืนสู่ฐานะเดิม และยังเรียกค่าเสียหายได้ [[law:ccc:391]]

## ระยะเวลา
กฎหมายใช้คำว่า "ระยะเวลาพอสมควร" ไม่ได้กำหนดจำนวนวัน [[law:ccc:387]] ความพอสมควรขึ้นกับลักษณะงานหรือสินค้า

## ข้อควรระวัง
- เมื่อแสดงเจตนาเลิกสัญญาแล้ว ถอนไม่ได้ [[law:ccc:386#p2]] ควรตัดสินใจให้แน่ก่อนส่ง
- ถ้าเป็นเรื่องความชำรุดบกพร่องของสินค้า ให้ดูอายุความหนึ่งปีด้วย ดู [[guide:notify-seller-of-defects]]
