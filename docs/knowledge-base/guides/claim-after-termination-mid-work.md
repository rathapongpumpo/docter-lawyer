# เรียกค่างานและค่าเสียหายเมื่อผู้ว่าจ้างเลิกสัญญากลางงาน

## ภาพรวม
ระหว่างที่งานยังไม่เสร็จ ผู้ว่าจ้างบอกเลิกสัญญาได้ เมื่อเสียค่าสินไหมทดแทนให้ผู้รับจ้างเพื่อความเสียหายจากการเลิกสัญญา [[law:ccc:605]]
เมื่อมีการใช้สิทธิเลิกสัญญา การงานที่ทำให้แล้วชดใช้ด้วยเงินตามควรค่า หรือตามที่สัญญากำหนด [[law:ccc:391#p3]]

## ใครใช้คู่มือนี้ได้
ผู้รับจ้างที่ถูกผู้ว่าจ้างบอกเลิกสัญญาจ้างทำของก่อนงานเสร็จ

## เอกสารที่ควรเตรียม
- [ ] สัญญาจ้างและงวดงาน (`contract`)
- [ ] หนังสือหรือข้อความบอกเลิกสัญญา (`termination_message`)
- [ ] รูปถ่ายและบันทึกสภาพงาน ณ วันที่ถูกเลิก (`work_record`)
- [ ] สรุปค่างานที่ทำแล้ว ค่าวัสดุ และความเสียหายอื่น (`cost_summary`)
- [ ] หนังสือทวงถาม (`demand_letter`)

## ขั้นตอน
1. ขอให้ผู้ว่าจ้างยืนยันการเลิกสัญญาและเหตุผลเป็นหนังสือ (คำแนะนำเชิงปฏิบัติ)
2. บันทึกและถ่ายภาพสภาพงาน ณ วันที่ถูกเลิก
3. ตรวจงวดงานที่ส่งมอบแล้ว ถ้าสัญญาแบ่งงวดและระบุสินจ้างเป็นส่วน ๆ สินจ้างของงวดที่รับมอบแล้วพึงใช้เมื่อรับงวดนั้น [[law:ccc:602#p2]]
4. สรุปจำนวนเงินที่เรียก แยกเป็นค่างานที่ทำแล้ว [[law:ccc:391#p3]] และค่าสินไหมทดแทนจากการเลิกสัญญา [[law:ccc:605]]
5. ส่งหนังสือทวงถามถึงผู้ว่าจ้าง
6. ถ้าไม่ได้รับชำระ ปรึกษาทนายความ หรือพิจารณาการไกล่เกลี่ย

## ระยะเวลา
- ผู้ประกอบการที่เรียกค่าการงานที่ได้ทำ ม.193/34 (๑) กำหนดอายุความสองปี เว้นแต่ทำเพื่อกิจการของฝ่ายลูกหนี้เอง [[law:ccc:193/34]]
- ถ้าไม่มีกฎหมายบัญญัติไว้โดยเฉพาะ อายุความเป็นสิบปี [[law:ccc:193/30]]

## ข้อควรระวัง
- ถ้าผู้ว่าจ้างอ้างว่าเลิกสัญญาเพราะคุณผิดสัญญา เช่น ทำงานชักช้า [[law:ccc:593]] ผลอาจต่างจากการเลิกตาม ม.605 ควรปรึกษาผู้เชี่ยวชาญ
- สัญญาอาจมีข้อตกลงเรื่องการเลิกสัญญาหรือการระงับข้อพิพาทไว้เป็นพิเศษ ให้อ่านก่อน
