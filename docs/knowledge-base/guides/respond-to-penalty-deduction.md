# รับมือเมื่อถูกหักค่าปรับส่งงานล่าช้า

## ภาพรวม
ค่าปรับที่ตกลงไว้ในสัญญาคือ [[term:เบี้ยปรับ]] [[law:ccc:379]] คู่มือนี้ช่วยตรวจ 3 ประเด็นที่กฎหมายเปิดไว้ ก่อนตัดสินใจจ่ายหรือโต้แย้ง

## ใครใช้คู่มือนี้ได้
ผู้รับจ้างหรือผู้ขายที่ส่งงานหรือของช้า และถูกอีกฝ่ายเรียกหรือหักค่าปรับ

## เอกสารที่ควรเตรียม
- [ ] สัญญาและข้อค่าปรับ (`contract`)
- [ ] บันทึกการรับมอบงาน (`acceptance_record`)
- [ ] หลักฐานเหตุล่าช้า เช่น คำสั่งแก้แบบ การส่งพื้นที่หรือสัมภาระช้า (`delay_evidence`)
- [ ] หลักฐานการจ่ายเงินหรือการหักเงิน (`payment_record`)
- [ ] หนังสือโต้แย้ง (`objection_letter`)

## ขั้นตอน
1. **ตรวจการสงวนสิทธิ** ถ้าอีกฝ่ายรับงานแล้วโดยไม่ได้บอกสงวนสิทธิเรียกเบี้ยปรับไว้ในเวลารับ เขาจะเรียกเบี้ยปรับไม่ได้ [[law:ccc:381#p3]]
2. **ตรวจเหตุที่ล่าช้า**
   - งานช้าเพราะสัมภาระหรือคำสั่งของผู้ว่าจ้าง ผู้รับจ้างไม่ต้องรับผิด เว้นแต่รู้ว่าไม่เหมาะหรือไม่ถูกต้องและไม่ได้เตือน [[law:ccc:591]]
   - ไม่ได้ชำระหนี้เพราะพฤติการณ์ที่คุณไม่ต้องรับผิดชอบ ยังไม่ถือว่าผิดนัด [[law:ccc:205]]
   - ถ้าอีกฝ่ายมีส่วนก่อความเสียหาย ค่าสินไหมทดแทนต้องอาศัยพฤติการณ์เป็นประมาณ [[law:ccc:223]]
3. **ประเมินว่าค่าปรับสูงเกินส่วนหรือไม่** ศาลลดเบี้ยปรับที่สูงเกินส่วนได้ โดยพิเคราะห์ทางได้เสียทุกอย่างอันชอบด้วยกฎหมายของเจ้าหนี้ [[law:ccc:383]]
4. **ถ้าเป็นสัญญาสำเร็จรูปของอีกฝ่าย** ข้อตกลงที่ทำให้อีกฝ่ายได้เปรียบเกินสมควร มีผลบังคับเพียงเท่าที่เป็นธรรม [[law:unfair_terms_2540:4#p1]]
5. **ทำหนังสือโต้แย้งหรือขอเจรจา** ใช้แบบ [[template:penalty-objection]]
6. **ถ้าตกลงกันไม่ได้** พิจารณาไกล่เกลี่ย หรือปรึกษาทนายความก่อนฟ้องเรียกเงินที่ถูกหัก (คำแนะนำเชิงปฏิบัติ)

## ข้อควรระวัง
- ถ้าจ่ายเงินตามเบี้ยปรับไปแล้ว สิทธิขอลดจะขาดไป [[law:ccc:383]]
- การที่อีกฝ่าย "หัก" ค่าปรับจากค่าจ้าง จะนับเป็นการใช้เงินตามเบี้ยปรับหรือไม่ ตัวบทไม่ได้ระบุ ควรปรึกษาผู้เชี่ยวชาญก่อนยอมรับการหักเงิน
