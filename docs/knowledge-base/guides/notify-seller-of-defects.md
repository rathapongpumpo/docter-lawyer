# แจ้งผู้ขายเมื่อสินค้าชำรุดบกพร่อง

## ภาพรวม
ผู้ขายต้องรับผิดในความชำรุดบกพร่องที่ทำให้ทรัพย์สินเสื่อมราคาหรือเสื่อมความเหมาะสมแก่ประโยชน์ แม้ผู้ขายไม่รู้ว่ามีความชำรุด [[law:ccc:472]]
แต่ต้องฟ้องภายในหนึ่งปีนับแต่พบเห็นความชำรุดบกพร่อง [[law:ccc:474]]

## ใครใช้คู่มือนี้ได้
ผู้ซื้อที่ได้รับสินค้าชำรุดบกพร่องจากผู้ขายหรือซัพพลายเออร์

## เอกสารที่ควรเตรียม
- [ ] สัญญาซื้อขายหรือใบสั่งซื้อ (`purchase_contract`)
- [ ] ใบส่งของและใบรับสินค้า ระบุวันที่และล็อต (`delivery_note`)
- [ ] รูปถ่ายและผลตรวจที่แสดงจุดชำรุด (`defect_evidence`)
- [ ] หนังสือแจ้งความชำรุดบกพร่อง (`defect_notice`)

## ขั้นตอน
1. **ตอนรับของ** ถ้าเห็นความชำรุดได้ชัด ให้ทักท้วงทันที เพราะถ้ารับไว้โดยไม่อิดเอื้อน ผู้ขายไม่ต้องรับผิด [[law:ccc:473]]
2. **ถ้าส่งของขาด เกิน หรือปนของอื่น** ในการซื้อขายสังหาริมทรัพย์ คุณปัดไม่รับได้ตามที่ ม.465 กำหนด [[law:ccc:465]]
3. **บันทึกวันที่พบความชำรุดของแต่ละล็อต** อายุความหนึ่งปีนับจากวันที่พบเห็น [[law:ccc:474]]
4. **ส่งหนังสือแจ้งความชำรุดบกพร่อง** ขอให้เปลี่ยนหรือแก้ไข ใช้แบบ [[template:defect-notice]] (คำแนะนำเชิงปฏิบัติ)
5. **ถ้าผู้ขายไม่แก้ไข** บอกกล่าวให้ชำระหนี้ภายในระยะเวลาพอสมควร แล้วเลิกสัญญาได้ [[law:ccc:387]] ดู [[guide:notice-to-cure-then-terminate]]
6. **เรียกค่าเสียหาย** ที่เกิดจากการไม่ชำระหนี้ให้ต้องตามความประสงค์ของมูลหนี้ [[law:ccc:215]]

## ระยะเวลา
- ฟ้องภายในหนึ่งปีนับแต่พบเห็นความชำรุดบกพร่อง [[law:ccc:474]]

## ข้อควรระวัง
- ผู้ขายไม่ต้องรับผิด ถ้าผู้ซื้อรู้หรือควรรู้ถึงความชำรุดในเวลาซื้อขาย หรือทรัพย์สินได้ขายทอดตลาด [[law:ccc:473]]
- ม.193/14 ไม่ได้ระบุการส่งหนังสือแจ้งไว้เป็นเหตุให้อายุความสะดุดหยุดลง อย่าวางใจว่าการแจ้งจะยืดอายุความ [[law:ccc:193/14]]
