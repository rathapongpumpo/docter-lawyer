# สงวนสิทธิเรียกค่าปรับเมื่อรับงานหรือของที่ส่งช้า

## ภาพรวม
ถ้าสัญญามีเบี้ยปรับกรณีชำระหนี้ไม่ถูกต้อง เช่น ส่งไม่ตรงเวลา เจ้าหนี้เรียกให้ชำระหนี้และเรียกเบี้ยปรับได้ด้วย [[law:ccc:381#p1]]
แต่ถ้าเจ้าหนี้ยอมรับชำระหนี้แล้ว จะเรียกเบี้ยปรับได้ต่อเมื่อบอกสงวนสิทธิไว้ในเวลารับชำระหนี้ [[law:ccc:381#p3]]

## ใครใช้คู่มือนี้ได้
ฝ่ายที่รับงานหรือรับของ (เจ้าหนี้) ซึ่งอีกฝ่ายส่งช้า และสัญญามีข้อเบี้ยปรับ
ถ้าคุณเป็นฝ่ายที่ส่งช้า ให้ดู [[guide:respond-to-penalty-deduction]]

## เอกสารที่ควรเตรียม
- [ ] สัญญาที่มีข้อเบี้ยปรับ (`contract`)
- [ ] บันทึกการรับมอบงานหรือใบรับของ (`acceptance_record`)
- [ ] หนังสือสงวนสิทธิ (`reservation_letter`)

## ขั้นตอน
1. ก่อนวันรับงาน ตรวจข้อสัญญาเรื่องเบี้ยปรับและการตรวจรับ
2. ในเวลารับงาน แจ้งสงวนสิทธิเรียกเบี้ยปรับ [[law:ccc:381#p3]]
3. ทำเป็นหนังสือ หรือเขียนในบันทึกการรับมอบ เพื่อใช้เป็นหลักฐาน (คำแนะนำเชิงปฏิบัติ — ตัวบทไม่ได้กำหนดรูปแบบ) ใช้แบบ [[template:reservation-of-rights]]
4. ถ้าพบความชำรุดบกพร่องในเวลารับ ให้ทักท้วงไว้ด้วย เพราะถ้ารับงานที่ชำรุดโดยไม่อิดเอื้อน ผู้รับจ้างอาจไม่ต้องรับผิด [[law:ccc:598]] และในสัญญาซื้อขาย ถ้าความชำรุดเห็นประจักษ์ในเวลาส่งมอบแล้วรับไว้โดยไม่อิดเอื้อน ผู้ขายไม่ต้องรับผิด [[law:ccc:473]]

## ระยะเวลา
ต้องสงวนสิทธิ "ในเวลารับชำระหนี้" [[law:ccc:381#p3]]

## ข้อควรระวัง
- การสงวนสิทธิภายหลังจากรับงานไปแล้ว ไม่ตรงกับถ้อยคำ "ในเวลารับชำระหนี้" ของ ม.381 วรรคสาม
- แม้สงวนสิทธิแล้ว ถ้าเบี้ยปรับสูงเกินส่วน ศาลอาจลดลงได้ [[law:ccc:383]]
