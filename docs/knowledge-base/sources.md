## วิธีตรวจยืนยันซ้ำ (ก่อนเปลี่ยนสถานะเป็น `in_review`)
1. เปิดต้นฉบับทางการของแต่ละมาตรา แล้วเทียบข้อความทีละคำกับไฟล์ใน `laws/`
   ต้นฉบับทางการคือราชกิจจานุเบกษาหรือระบบค้นหากฎหมายของสำนักงานคณะกรรมการกฤษฎีกา
2. ตรวจรายการกฎหมายแก้ไขเพิ่มเติม ป.พ.พ. ฉบับที่ 20–25 (พ.ศ. 2557–2568; รายการที่พบใน Wikisource สิ้นสุดที่ฉบับที่ 25 — ดู research/verification-worklist.md) ว่ามีฉบับใดแก้มาตราในไฟล์ `laws/ccc-*.md` หรือไม่ ถ้ามี ให้เพิ่มเวอร์ชันใหม่พร้อม `effective_from` ห้ามเขียนทับของเดิม
3. ตรวจว่ามีพระราชกฤษฎีกาออกตาม ป.พ.พ. ม.7 วรรคสอง เพื่อปรับอัตราดอกเบี้ยหรือไม่
4. บันทึกผลใน front-matter `verification.checked_against` ของแต่ละไฟล์ พร้อมวันที่และผู้ตรวจ
5. ไฟล์ใดที่ข้อความตัวบทเปลี่ยน ต้องตรวจบทความ คู่มือ และแบบฟอร์มที่อ้างมาตรานั้นทั้งหมด
