# สัญญาที่เสียเปรียบตั้งแต่ต้น กฎหมายช่วยอะไรได้บ้าง

## สรุปสั้น
- ถ้าเป็นสัญญาสำเร็จรูป หรือสัญญาระหว่างผู้บริโภคกับผู้ประกอบธุรกิจ ข้อตกลงที่ทำให้อีกฝ่ายได้เปรียบเกินสมควร มีผลบังคับได้เพียงเท่าที่เป็นธรรมและพอสมควรแก่กรณี [[law:unfair_terms_2540:4#p1]]
- กรณีมีข้อสงสัย ให้ตีความสัญญาสำเร็จรูปไปในทางที่เป็นคุณแก่ฝ่ายที่ไม่ได้กำหนดสัญญา [[law:unfair_terms_2540:4#p2]]
- แต่กฎหมายนี้ไม่ได้ทำให้ข้อตกลงที่เสียเปรียบหายไปทั้งหมด ศาลเป็นผู้วินิจฉัยว่ามีผลบังคับเพียงใด [[law:unfair_terms_2540:10]]
- ทางที่ดีที่สุดคือตรวจและเจรจาก่อนเซ็น (คำแนะนำเชิงปฏิบัติ)

## เรื่องนี้คืออะไร
[[term:สัญญาสำเร็จรูป]] คือสัญญาเป็นหนังสือ ที่มีการกำหนดข้อสัญญาที่เป็นสาระสำคัญไว้ล่วงหน้า ซึ่งคู่สัญญาฝ่ายหนึ่งนำมาใช้ในการประกอบกิจการของตน [[law:unfair_terms_2540:3]]

พ.ร.บ.ว่าด้วยข้อสัญญาที่ไม่เป็นธรรม ม.4 ใช้กับข้อตกลงใน 3 แบบ [[law:unfair_terms_2540:4#p1]]
- สัญญาระหว่างผู้บริโภคกับผู้ประกอบธุรกิจการค้าหรือวิชาชีพ
- สัญญาสำเร็จรูป
- สัญญาขายฝาก

สำหรับองค์กรที่ทำสัญญาธุรกิจกับอีกองค์กร ส่วนที่มักเกี่ยวข้องคือกรณี "สัญญาสำเร็จรูป" เพราะบทนิยามของ "ผู้บริโภค" ต้องเป็นการเข้าทำสัญญาโดยมิใช่เพื่อการค้า [[law:unfair_terms_2540:3]]

## ข้อตกลงแบบไหนที่อาจถือว่าทำให้ได้เปรียบ
ข้อตกลงที่ให้อีกฝ่ายปฏิบัติหรือรับภาระเกินกว่าที่วิญญูชนจะพึงคาดหมายได้ตามปกติ อาจถือได้ว่าทำให้ได้เปรียบ เช่น [[law:unfair_terms_2540:4#p3]]
1. ยกเว้นหรือจำกัดความรับผิดที่เกิดจากการผิดสัญญา
2. ให้ต้องรับผิดหรือรับภาระมากกว่าที่กฎหมายกำหนด
3. ให้สัญญาสิ้นสุดโดยไม่มีเหตุผลอันสมควร หรือให้บอกเลิกได้แม้อีกฝ่ายไม่ได้ผิดสัญญาในข้อสาระสำคัญ
4. ให้สิทธิไม่ปฏิบัติตามสัญญา หรือปฏิบัติล่าช้าได้โดยไม่มีเหตุผลอันสมควร
5. ให้สิทธิฝ่ายหนึ่งเพิ่มภาระให้อีกฝ่ายมากกว่าภาระในเวลาทำสัญญา

ศาลพิจารณาว่าข้อสัญญาควรมีผลเพียงใด โดยดูพฤติการณ์ทั้งปวง รวมทั้งอำนาจต่อรอง ฐานะทางเศรษฐกิจ ความรู้ความเข้าใจ ปกติประเพณีของสัญญาชนิดนั้น และภาระที่หนักกว่ากันมาก [[law:unfair_terms_2540:10]]

## กฎหมายอื่นที่เกี่ยวข้อง
- ข้อตกลงที่จำกัดเสรีภาพในการประกอบอาชีพหรือธุรกิจ ถ้าทำให้รับภาระมากกว่าที่คาดหมายได้ตามปกติ มีผลบังคับได้เพียงเท่าที่เป็นธรรม [[law:unfair_terms_2540:5]]
- ข้อตกลงที่ทำไว้ล่วงหน้าเพื่อยกเว้นความรับผิดเพื่อความเสียหายต่อชีวิต ร่างกาย หรืออนามัย ที่เกิดจากการกระทำโดยจงใจหรือประมาทเลินเล่อ นำมาอ้างไม่ได้ [[law:unfair_terms_2540:8#p1]]
- ถ้ามีกรณีต้องริบมัดจำ และมัดจำสูงเกินส่วน ศาลลดลงให้ริบได้เพียงเท่าความเสียหายที่แท้จริง [[law:unfair_terms_2540:7]]
- เบี้ยปรับที่สูงเกินส่วน ศาลลดลงเป็นจำนวนพอสมควรได้ [[law:ccc:383]]
- ข้อสัญญาที่ห้ามไม่ให้นำ พ.ร.บ.นี้ไปใช้บังคับ เป็นโมฆะ [[law:unfair_terms_2540:11]]
- สัญญาตีความไปตามความประสงค์ในทางสุจริต โดยพิเคราะห์ถึงปกติประเพณีด้วย [[law:ccc:368]] และการตีความการแสดงเจตนาให้เพ่งเล็งถึงเจตนาอันแท้จริงยิ่งกว่าถ้อยคำ [[law:ccc:171]]
- การใดมีวัตถุประสงค์ต้องห้ามชัดแจ้งโดยกฎหมาย พ้นวิสัย หรือขัดต่อความสงบเรียบร้อยหรือศีลธรรมอันดี การนั้นเป็นโมฆะ [[law:ccc:150]]

## ต้องทำอย่างไร (ก่อนเซ็นสัญญา)
คำแนะนำเชิงปฏิบัติ
1. หาข้อค่าปรับ และดูว่ามีเพดานหรือไม่
2. หาข้อการตรวจรับงาน และการสงวนสิทธิเรียกค่าปรับ
3. หาข้อเลิกสัญญา ดูว่าอีกฝ่ายเลิกได้โดยคุณไม่ได้ผิดสัญญาหรือไม่
4. หาข้อจำกัดความรับผิดของอีกฝ่าย
5. หาข้อความชำรุดบกพร่องและระยะเวลารับประกัน
6. จดประเด็นที่ต้องการเจรจา และขอแก้เป็นหนังสือ

## เมื่อไรควรปรึกษาทนายความ
- สัญญามูลค่าสูง หรือระยะยาว
- อีกฝ่ายไม่ยอมแก้ข้อที่คุณเห็นว่าเสียเปรียบมาก
- มีข้อจำกัดการประกอบธุรกิจ หรือข้อระงับข้อพิพาทที่คุณไม่เข้าใจ
