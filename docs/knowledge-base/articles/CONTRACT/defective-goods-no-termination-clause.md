# ซัพพลายเออร์ส่งของไม่ได้มาตรฐาน แต่สัญญาไม่มีข้อให้เลิกสัญญา

## สรุปสั้น
- สิทธิเลิกสัญญาเกิดได้ทั้งจากข้อสัญญาและจากบทบัญญัติของกฎหมาย [[law:ccc:386]]
- ถ้าคู่สัญญาไม่ชำระหนี้ คุณกำหนดระยะเวลาพอสมควรแล้วบอกกล่าวให้ชำระได้ ถ้ายังไม่ชำระภายในเวลานั้น คุณเลิกสัญญาได้ [[law:ccc:387]]
- ผู้ขายต้องรับผิดในความชำรุดบกพร่องที่ทำให้ทรัพย์สินเสื่อมราคาหรือเสื่อมความเหมาะสมแก่ประโยชน์ [[law:ccc:472]]
- ต้องฟ้องเรื่องความชำรุดบกพร่องภายในหนึ่งปีนับแต่พบเห็นความชำรุดบกพร่อง [[law:ccc:474]]

## เรื่องนี้คืออะไร
ในสัญญาซื้อขาย ผู้ขายโอนกรรมสิทธิ์ และผู้ซื้อตกลงใช้ราคา [[law:ccc:453]] ผู้ขายต้องส่งมอบทรัพย์สินที่ขาย [[law:ccc:461]]

ถ้าทรัพย์สินที่ขายชำรุดบกพร่อง จนเสื่อมราคาหรือเสื่อมความเหมาะสมแก่ประโยชน์ที่มุ่งใช้ตามปกติ หรือประโยชน์ที่มุ่งหมายโดยสัญญา ผู้ขายต้องรับผิด [[law:ccc:472#p1]] แม้ผู้ขายจะไม่รู้ว่ามีความชำรุดบกพร่องก็ตาม [[law:ccc:472#p2]]

## สิทธิของคุณ (กรณีคุณเป็นผู้ซื้อ)
1. **ให้ผู้ขายรับผิดในความชำรุดบกพร่อง** [[law:ccc:472]]
2. **เรียกค่าสินไหมทดแทน** เมื่อลูกหนี้ไม่ชำระหนี้ให้ต้องตามความประสงค์อันแท้จริงแห่งมูลหนี้ [[law:ccc:215]] ค่าเสียหายที่เรียกได้คือความเสียหายที่ตามปกติย่อมเกิดจากการไม่ชำระหนี้ และความเสียหายจากพฤติการณ์พิเศษที่คู่กรณีคาดเห็นหรือควรคาดเห็นล่วงหน้า [[law:ccc:222]]
3. **บอกกล่าวแล้วเลิกสัญญา** แม้สัญญาไม่มีข้อให้เลิก กฎหมายให้กำหนดระยะเวลาพอสมควร บอกกล่าวให้ชำระหนี้ ถ้าไม่ชำระภายในเวลานั้นก็เลิกสัญญาได้ [[law:ccc:387]] การเลิกสัญญาทำโดยแสดงเจตนาแก่อีกฝ่าย และถอนไม่ได้ [[law:ccc:386]]
4. **ถ้าเวลาส่งมอบเป็นสาระสำคัญ** และพ้นกำหนดโดยไม่มีการชำระหนี้ เลิกสัญญาได้โดยไม่ต้องบอกกล่าวก่อน [[law:ccc:388]]
5. **ถ้าส่งของขาดหรือเกินจำนวน หรือปนของอื่น** ในการซื้อขายสังหาริมทรัพย์ ผู้ซื้อปฏิเสธไม่รับได้ตามที่ ม.465 กำหนด [[law:ccc:465]]
6. **ผลเมื่อเลิกสัญญาแล้ว** แต่ละฝ่ายต้องให้อีกฝ่ายกลับคืนสู่ฐานะเดิม เงินที่ต้องคืนให้บวกดอกเบี้ยนับแต่เวลาที่ได้รับไว้ และการเลิกสัญญาไม่กระทบสิทธิเรียกค่าเสียหาย [[law:ccc:391]]

## ข้อควรระวัง
ผู้ขายไม่ต้องรับผิดในกรณีต่อไปนี้ [[law:ccc:473]]
- ผู้ซื้อรู้อยู่แล้วในเวลาซื้อขายว่ามีความชำรุดบกพร่อง หรือควรรู้ถ้าใช้ความระมัดระวังอย่างวิญญูชน
- ความชำรุดบกพร่องเห็นประจักษ์ในเวลาส่งมอบ และผู้ซื้อรับทรัพย์สินไว้โดยไม่อิดเอื้อน
- ทรัพย์สินนั้นได้ขายทอดตลาด

จึงแนะนำให้ทักท้วงเป็นหนังสือทุกครั้งที่รับของแล้วพบความชำรุดที่เห็นได้ (คำแนะนำเชิงปฏิบัติ)

ถ้าเป็นสัญญาสำเร็จรูปที่ผู้ขายกำหนด และมีข้อตกลงยกเว้นหรือจำกัดความรับผิดที่เกิดจากการผิดสัญญา ข้อตกลงแบบนั้นอาจถือได้ว่าทำให้ได้เปรียบคู่สัญญาอีกฝ่าย [[law:unfair_terms_2540:4#p3]]

## ต้องทำอย่างไร
คำแนะนำเชิงปฏิบัติ (ไม่ใช่ขั้นตอนที่กฎหมายบังคับ)
1. บันทึกวันที่พบความชำรุดบกพร่องของแต่ละล็อต เพราะอายุความหนึ่งปีนับจากวันที่พบเห็น [[law:ccc:474]]
2. เก็บหลักฐาน เช่น รูปถ่าย ผลตรวจสเปก ใบส่งของ
3. ส่งหนังสือแจ้งความชำรุดบกพร่องถึงผู้ขาย ดู [[guide:notify-seller-of-defects]]
4. ถ้าต้องการเลิกสัญญา ส่งหนังสือบอกกล่าวให้แก้ไขภายในเวลาพอสมควรก่อน ดู [[guide:notice-to-cure-then-terminate]]

## เอกสารที่ควรเตรียม
- สัญญาซื้อขายหรือใบสั่งซื้อ
- ใบส่งของและใบรับสินค้า ที่ระบุวันที่และล็อต
- รูปถ่ายและผลตรวจสินค้า
- หนังสือหรือข้อความที่เคยแจ้งปัญหา

## ระยะเวลา
- ฟ้องเรื่องความชำรุดบกพร่องได้ภายในหนึ่งปีนับแต่พบเห็นความชำรุดบกพร่อง [[law:ccc:474]]
- ระยะเวลาที่ให้แก้ไขตาม ม.387 กฎหมายใช้คำว่า "ระยะเวลาพอสมควร" ไม่ได้กำหนดจำนวนวัน [[law:ccc:387]]

## เมื่อไรควรปรึกษาทนายความ
- ใกล้ครบหนึ่งปีนับจากวันที่พบความชำรุดบกพร่อง
- ผู้ขายโต้แย้งว่าคุณรับของไว้โดยไม่อิดเอื้อน
- มูลค่าสินค้าหรือความเสียหายสูง
