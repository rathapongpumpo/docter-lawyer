# หนังสือแจ้งความชำรุดบกพร่องของสินค้า

> **ก่อนส่ง:** แบบนี้เป็นโครงหนังสือทั่วไป ไม่ใช่คำปรึกษาเฉพาะเรื่องของคุณ ควรให้ผู้มีความรู้ด้านกฎหมายตรวจก่อนส่ง
> โดยเฉพาะเมื่อมูลค่าสูง หรือใกล้ครบอายุความ แบบนี้ไม่ใช่คำฟ้องหรือเอกสารที่ยื่นต่อศาล

## ใช้เมื่อไร
สินค้าที่ได้รับชำรุดบกพร่องจนเสื่อมราคาหรือเสื่อมความเหมาะสมแก่ประโยชน์ [[law:ccc:472]] ควรแจ้งโดยเร็ว เพราะต้องฟ้องภายในหนึ่งปีนับแต่พบเห็นความชำรุดบกพร่อง [[law:ccc:474]] ดู [[guide:notify-seller-of-defects]]

## ฐานกฎหมาย
[[law:ccc:472]] [[law:ccc:473]] [[law:ccc:474]]

## ช่องที่ต้องกรอก
- [ที่อยู่ผู้ส่ง] [วันที่]
- [ชื่อคู่สัญญา] [ที่อยู่คู่สัญญา]
- [ชื่อ/เลขที่สัญญา] [วันที่ทำสัญญา]
- [ชื่อผู้ลงนาม] [ตำแหน่ง] (ถ้าส่งในนามนิติบุคคล ผู้ลงนามต้องมีอำนาจกระทำการแทน)
- [สินค้า ล็อต และวันที่รับ] [วันที่พบความชำรุด]
- [ลักษณะความชำรุดบกพร่องและหลักฐานแนบ]
- [สิ่งที่ขอ เช่น เปลี่ยนสินค้า แก้ไข หรือลดราคา] [ระยะเวลาที่ขอให้ดำเนินการ]

## ตัวหนังสือ
```text
[ที่อยู่ผู้ส่ง]
วันที่ [วันที่]

เรื่อง  แจ้งความชำรุดบกพร่องของสินค้า
เรียน  [ชื่อคู่สัญญา]
อ้างถึง  [ชื่อ/เลขที่สัญญาหรือใบสั่งซื้อ] ลงวันที่ [วันที่ทำสัญญา]

[ชื่อผู้ส่ง] ได้รับ [สินค้า ล็อต และวันที่รับ] และพบเมื่อวันที่ [วันที่พบความชำรุด] ว่าสินค้ามีความชำรุดบกพร่อง ได้แก่ [ลักษณะความชำรุดบกพร่อง] ตามหลักฐานที่แนบมา

ความชำรุดบกพร่องดังกล่าวทำให้สินค้าเสื่อมความเหมาะสมแก่ประโยชน์ตามสัญญา ผู้ขายต้องรับผิดตามประมวลกฎหมายแพ่งและพาณิชย์ มาตรา ๔๗๒
จึงขอให้ท่าน [สิ่งที่ขอ] ภายใน [ระยะเวลาที่ขอให้ดำเนินการ]

ขอแสดงความนับถือ

[ชื่อผู้ลงนาม]
[ตำแหน่ง]
```

## คำแนะนำการส่ง (เชิงปฏิบัติ)
- ส่งทางช่องทางที่พิสูจน์ได้ว่าอีกฝ่ายได้รับ เช่น ไปรษณีย์ลงทะเบียนตอบรับ และเก็บใบตอบรับไว้
- เก็บสำเนาหนังสือที่ลงนามแล้วไว้กับเอกสารสัญญา
