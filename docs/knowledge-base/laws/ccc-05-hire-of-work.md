# ป.พ.พ. — จ้างทำของ

ข้อความตัวบทในไฟล์นี้คัดลอกจากแหล่งตาม `sources.md` ตามที่ถอดจากไฟล์ PDF โดยไม่เรียบเรียงใหม่ ห้ามแก้ข้อความตัวบทด้วยมือ ยกเว้นแก้ให้ตรงกับต้นฉบับที่ตรวจแล้ว และต้องบันทึกเหตุผลไว้ในหมายเหตุของมาตรานั้น

### มาตรา ๕๘๗

อันว่าจ้างทำของนั้น คือสัญญาซึ่งบุคคลคนหนึ่งเรียกว่าผู้รับจ้าง

ตกลงจะทำการงานสิ่งใดสิ่งหนึ่งจนสำเร็จให้แก่บุคคลอีกคนหนึ่ง เรียกว่าผู้ว่าจ้าง และผู้ว่าจ้างตกลงจะให้สินจ้างเพื่อผลสำเร็จแห่งการที่ทำนั้น

> หมายเหตุการถอดข้อความ: การขึ้นบรรทัดใหม่หลังคำว่า "ผู้รับจ้าง" มาจากการแปลง PDF ไม่ใช่การขึ้นวรรคใหม่

### มาตรา ๕๙๑

ถ้าความชำรุดบกพร่องหรือความชักช้าในการที่ทำนั้นเกิดขึ้นเพราะสภาพแห่งสัมภาระซึ่งผู้ว่าจ้างส่งให้ก็ดี เพราะคำสั่งของผู้ว่าจ้างก็ดี ท่านว่าผู้รับจ้างไม่ต้องรับผิดเว้นแต่จะได้รู้อยู่แล้วว่าสัมภาระนั้นไม่เหมาะหรือว่าคำสั่งนั้นไม่ถูกต้องและมิได้บอกกล่าวตักเตือน

แหล่งที่มา: S1

### มาตรา ๕๙๒

ผู้รับจ้างจำต้องยอมให้ผู้ว่าจ้างหรือตัวแทนของผู้ว่าจ้างตรวจตราการงานได้ตลอดเวลาที่ทำอยู่นั้น

แหล่งที่มา: S1

### มาตรา ๕๙๓

ถ้าผู้รับจ้างไม่เริ่มทำการในเวลาอันควร หรือทำการชักช้าฝ่าฝืนข้อกำหนดแห่งสัญญาก็ดี หรือทำการชักช้าโดยปราศจากความผิดของผู้ว่าจ้าง จนอาจคาดหมายล่วงหน้าได้ว่าการนั้นจะไม่สำเร็จภายในกำหนดเวลาที่ได้ตกลงกันไว้ก็ดี ผู้ว่าจ้างชอบที่จะเลิกสัญญาเสียได้ มิพักต้องรอคอยให้ถึงเวลากำหนดส่งมอบของนั้นเลย

แหล่งที่มา: S1

### มาตรา ๕๙๔

ถ้าในระหว่างเวลาที่ทำการอยู่นั้นเป็นวิสัยจะคาดหมายล่วงหน้าได้แน่นอนว่า การที่ทำนั้นจะสำเร็จอย่างบกพร่องหรือจะเป็นไปในทางอันฝ่าฝืนข้อสัญญาเพราะความผิดของผู้รับจ้างไซร้ ผู้ว่าจ้างจะบอกกล่าวให้ผู้รับจ้างแก้ไขสิ่งที่บกพร่องให้คืนดี หรือทำการให้เป็นไปตามสัญญาภายในเวลาอันสมควรซึ่งกำหนดให้ในคำบอกกล่าวนั้นก็ได้ ถ้าและคลาดกำหนดนั้นไป ท่านว่าผู้ว่าจ้างชอบที่จะเอาการนั้นให้บุคคลภายนอกซ่อมแซมหรือทำต่อไปได้ซึ่งผู้รับจ้างจะต้องเสี่ยงความเสียหายและออกค่าใช้จ่ายทั้งสิ้น

แหล่งที่มา: S1

### มาตรา ๕๙๖

ถ้าผู้รับจ้างส่งมอบการที่ทำไม่ทันเวลาที่ได้กำหนดไว้ในสัญญาก็ดีหรือถ้าไม่ได้กำหนดเวลาไว้ในสัญญาเมื่อล่วงพ้นเวลาอันควรแก่เหตุก็ดี ผู้ว่าจ้างชอบที่จะลดสินจ้างลง หรือถ้าสาระสำคัญแห่งสัญญาอยู่ที่เวลา ก็ชอบที่จะเลิกสัญญาได้

แหล่งที่มา: S1

### มาตรา ๕๙๘

ถ้าผู้ว่าจ้างยอมรับมอบการที่ทำนั้นแล้วทั้งชำรุดบกพร่องมิได้อิดเอื้อนโดยแสดงออกชัดหรือโดยปริยาย ผู้รับจ้างก็ไม่ต้องรับผิด เว้นแต่ความชำรุดบกพร่องนั้นเป็นเช่นจะไม่พึงพบได้ในขณะเมื่อรับมอบหรือผู้รับจ้างได้ปิดบังความนั้นเสีย

แหล่งที่มา: S1

### มาตรา ๖๐๐

ถ้ามิได้กำหนดไว้เป็นอย่างอื่นในสัญญาไซร้ท่านว่าผู้รับจ้างจะต้องรับผิดเพื่อการที่ทำชำรุดบกพร่อง เพียงแต่ที่ปรากฏขึ้นภายในปีหนึ่งนับแต่วันส่งมอบ หรือที่ปรากฏขึ้นภายในห้าปี ถ้าการที่ทำนั้นเป็นสิ่งปลูกสร้างกับพื้นดิน นอกจากเรือนโรงทำด้วยเครื่องไม้

แต่ข้อจำกัดนี้ท่านมิให้ใช้บังคับเมื่อปรากฏว่าผู้รับจ้างได้ปิดบังความชำรุดบกพร่องนั้น

แหล่งที่มา: S1

### มาตรา ๖๐๑

ท่านห้ามมิให้ฟ้องผู้รับจ้างเมื่อพ้นปีหนึ่ง นับแต่วันการชำรุดบกพร่องได้ปรากฏขึ้น

แหล่งที่มา: S1

### มาตรา ๖๐๒

อันสินจ้างนั้นพึงใช้ให้เมื่อรับมอบการที่ทำ

ถ้าการที่ทำนั้นมีกำหนดว่าจะส่งรับกันเป็นส่วน ๆ และได้ระบุจำนวนสินจ้างไว้เป็นส่วน ๆ ไซร้ ท่านว่าพึงใช้สินจ้างเพื่อการแต่ละส่วนในเวลารับเอาส่วนนั้น

แหล่งที่มา: S1

### มาตรา ๖๐๔

ถ้าผู้ว่าจ้างเป็นผู้จัดหาสัมภาระ และการที่จ้างทำนั้นพังทลายหรือบุบสลายลงก่อนได้ส่งมอบกันถูกต้องไซร้ ท่านว่าความวินาศนั้นตกเป็นพับแก่ผู้ว่าจ้าง หากความวินาศนั้นมิได้เป็นเพราะการกระทำของผู้รับจ้าง

ในกรณีเช่นว่านี้ สินจ้างก็เป็นอันไม่ต้องใช้ เว้นแต่ความวินาศนั้นเป็นเพราะการกระทำของผู้ว่าจ้าง

แหล่งที่มา: S1

### มาตรา ๖๐๕

ถ้าการที่จ้างยังทำไม่แล้วเสร็จอยู่ตราบใด  ผู้ว่าจ้างอาจบอกเลิกสัญญาได้ เมื่อเสียค่าสินไหมทดแทนให้แก่ผู้รับจ้างเพื่อความเสียหายอย่างใด ๆ อันเกิดแต่การเลิกสัญญานั้น

แหล่งที่มา: S1

### มาตรา ๖๐๗

ผู้รับจ้างจะเอาการที่รับจ้างทั้งหมดหรือแบ่งการแต่บางส่วนไปให้ผู้รับจ้างช่วงทำอีกทอดหนึ่งก็ได้ เว้นแต่สาระสำคัญแห่งสัญญานั้นจะอยู่ที่ความรู้ความสามารถของตัวผู้รับจ้าง แต่ผู้รับจ้างคงต้องรับผิดเพื่อความประพฤติหรือความผิดอย่างใด ๆ ของผู้รับจ้างช่วง

แหล่งที่มา: S1
