# ป.วิ.พ. — ศาลที่จะยื่นคำฟ้อง (มาตรา ๔)

ข้อความตัวบทในไฟล์นี้คัดลอกจากแหล่งตาม `sources.md` ตามที่ถอดจากไฟล์ PDF โดยไม่เรียบเรียงใหม่ ห้ามแก้ข้อความตัวบทด้วยมือ ยกเว้นแก้ให้ตรงกับต้นฉบับที่ตรวจแล้ว และต้องบันทึกเหตุผลไว้ในหมายเหตุของมาตรานั้น

> สร้างข้อความใหม่จากไฟล์ที่วรรณยุกต์บางตัวหายระหว่างแปลง PDF — ข้อความตรงกับผลค้นหาจากเว็บอื่น แต่ต้องตรวจกับต้นฉบับอีกครั้ง

### มาตรา ๔

เว้นแต่จะมีบทบัญญัติเป็นอย่างอื่น

(๑) คำฟ้องให้เสนอต่อศาลที่จำเลยมีภูมิลำเนาอยู่ในเขตศาล หรือต่อศาลที่มูลคดีเกิดขึ้นในเขตศาลไม่ว่าจำเลยจะมีภูมิลำเนาอยู่ในราชอาณาจักรหรือไม่

(๒) คำร้องขอ ให้เสนอต่อศาลที่มูลคดีเกิดขึ้นในเขตศาล หรือต่อศาลที่ผู้ร้องมีภูมิลำเนาอยู่ในเขตศาล
